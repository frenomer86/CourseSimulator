# Curriculum research: Software Engineering

Accessed 2026-10. University names appear only in this document. Figures marked "(not stated)" were not on the page that was retrieved; figures marked "(third-party)" come from an aggregator and need checking against the university. The shared web-search budget ran out part-way through, so several programme pages (Oxford's own course page, NUS MTech, Waterloo's credit totals) could only be reached through search summaries (see section 10).

## 1. Summary

- Software engineering is taught as a dedicated engineering degree (Waterloo, Victoria, Makerere), as a focus area or specialisation inside computer science (NUS has Software Engineering as one of 10 focus areas; ETH offers it as a master's specialisation), and as a practice-heavy master's (CMU, Oxford part-time, ANU).
- The ACM/IEEE undergraduate guidelines (SE2014) define the shared core: 10 knowledge areas totalling 467 recommended contact hours, about 10 full courses. Computing essentials take 152 hours, mathematical and engineering fundamentals 80, design 48, verification and validation 37, process 33, requirements 30, professional practice 29, modelling and analysis 28, security 20, quality 10. A capstone project is recommended as an essential element.
- Bachelor's size: Waterloo eight study terms of required courses plus 10 electives and a three-term design project in a co-op plan; Victoria 46 courses (71.5 credits) over 4 years and 8 months with four co-op terms; Makerere 4 years, 8 semesters of 15 to 19 credit units each, plus three 5-credit recess terms (two practical skills projects and a field attachment).
- Two features distinguish SE from CS: a longer, team-based design project (Waterloo SE 390/490/491, Makerere BSE4100/4200, CMU studio) and compulsory work experience (co-op at Waterloo and Victoria, field attachment at Makerere).
- Master's: CMU's legacy MSE was 16 months, 195 units: 60 core, 6 communication, 84 studio, 45 electives. Oxford's MSc is part-time, ten one-week modules plus a project course and a dissertation worth two modules. ANU's specialisation is 24 units chosen from a list of 6-unit courses (processes, requirements, project management, safety, systems engineering).
- PhD: CMU's SE PhD is milestone-driven (core and elective courses, one practicum, two TA assignments, speaking and writing requirements, 4-semester residency, thesis proposal, weekly seminar with two talks a year). Makerere's is 6 core courses of 3 units (research methods, writing and ethics, philosophy of computing, science of programming, software architectures, models of software systems) then a thesis.
- Platform: the current 21 courses cover practice well (requirements, OOSAD, architecture, testing, DevOps, security, HCI, project management) but lack the maths, systems and formal foundations, concurrency, evolution/maintenance and a capstone. All 21 are kept.

## 5. Common core across universities

Present in most of the Waterloo, Victoria, Makerere and SE2014 sources:

1. Programming in an object-oriented language plus data structures and algorithms.
2. Discrete mathematics and logic (Waterloo Logic and Computation, Makerere Formal Methods, SE2014 mathematical foundations 50 hours).
3. Calculus, linear algebra/statistics (Waterloo MATH and STAT, Makerere Mathematics for Software Engineers and Numerical Analysis).
4. Computer organisation, operating systems and networks (Waterloo, Makerere).
5. Databases and web development.
6. Requirements engineering (Waterloo SE 463, Makerere BSE2208).
7. Software design and architecture (Waterloo SE 464, Makerere BSE3210).
8. Testing, verification and quality (Waterloo SE 465, Makerere Testing and Verification, Software Quality Management).
9. Software process, project management and metrics (SE2014 33 hours of process; Makerere Software Metrics).
10. Security and ethics/professional practice.
11. Team design project over at least two terms and work experience.

## 6. Prerequisite chains

Stated on public pages:

- Waterloo term sequence: 1A programming (CS 137) and maths → 1B CS 138 → 2A Logic and Computation, CS 241 → 2B CS 240, CS 247 (design), CS 348 (databases) → 3A OS, Testing, CS 341 (algorithms) → 3B Design Project Planning, Software Design and Architectures, CS 343 → 4A Requirements, Design Project 1 → 4B Design Project 2. Advanced technical electives cannot be taken before 3A.
- Makerere: Y1 programming and OOP I → Y2 OOP II, Data Structures → Y3 Software Architecture and Patterns, Testing and Verification → Y4 Software Engineering Project I and II. Recess projects each summer.
- CMU legacy MSE: systems prerequisite (6 units) → core courses → Studio I to III.

Proposed platform chains (study order):

- Programming: principles-of-programming → introduction-to-python → programming-with-cpp → data-structures-and-algorithms → software-development-with-java → advanced-software-development-with-java → Concurrent and Parallel Programming.
- Foundations: discrete-mathematics → Logic and Formal Methods; calculus and linear-algebra-for-data-science → probability-and-statistics.
- Systems: computer-organization-and-architecture → operating-systems → computer-networking-i → database-systems-and-design → web-application-programming-i → web-application-programming-ii.
- Practice: software-engineering → requirements-engineering → object-oriented-system-analysis-and-design → software-architecture-and-design-patterns → software-testing-and-quality-assurance → version-control-and-devops → secure-software-development → Software Maintenance and Evolution → it-project-management → Computing Capstone Project.
- Master's: Graduate Research Methods → Advanced Software Architecture / Software Analysis and Verification / Advanced Software Process and Project Management → Software Engineering Studio.
- PhD: Doctoral Research Seminar in Software Engineering + Graduate Research Methods → Empirical Software Engineering → electives.

## 9. Proposed structure

New bachelor courses (4): Logic and Formal Methods; Concurrent and Parallel Programming; Software Maintenance and Evolution; Computing Capstone Project. New master's courses (7): Graduate Research Methods; Advanced Software Architecture; Software Analysis and Verification; Advanced Software Process and Project Management; Software Engineering Studio; Empirical Software Engineering; Software Safety and Dependability. New PhD course (1): Doctoral Research Seminar in Software Engineering.

### Bachelor of Science in Software Engineering (4 years)

- Core (30, in study order): principles-of-programming, introduction-to-python, discrete-mathematics, calculus, linear-algebra-for-data-science, probability-and-statistics, programming-with-cpp, data-structures-and-algorithms, software-development-with-java, Logic and Formal Methods (new), computer-organization-and-architecture, database-systems-and-design, operating-systems, computer-networking-i, software-engineering, requirements-engineering, object-oriented-system-analysis-and-design, web-application-programming-i, version-control-and-devops, human-computer-interaction, software-architecture-and-design-patterns, software-testing-and-quality-assurance, web-application-programming-ii, advanced-software-development-with-java, Concurrent and Parallel Programming (new), secure-software-development, it-project-management, Software Maintenance and Evolution (new), legal-and-ethical-issues-in-computing, Computing Capstone Project (new).
- Electives (10), choose 4: mobile-application-development, programming-with-c, artificial-intelligence, machine-learning, cloud-computing, containers-and-kubernetes, site-reliability-engineering, information-security, embedded-systems, research-methods-in-computer-science.
- Total pool 40; a student takes 34.

### Master of Science in Software Engineering (1 to 2 years)

- Core (5): Graduate Research Methods, Advanced Software Architecture, Software Analysis and Verification, Advanced Software Process and Project Management, Software Engineering Studio.
- Electives (8), choose 4: Empirical Software Engineering, Software Safety and Dependability, requirements-engineering, secure-software-development, distributed-systems, site-reliability-engineering, mlops-and-model-deployment, human-computer-interaction.
- Milestones: studio with an external client; research or practice project proposal; dissertation or practicum report; oral defence or final studio presentation.

### Doctor of Philosophy in Software Engineering (4 to 5 years)

- Core (3): Doctoral Research Seminar in Software Engineering, Graduate Research Methods, Empirical Software Engineering.
- Electives (7), choose 3: Advanced Software Architecture, Software Analysis and Verification, Software Safety and Dependability, Advanced Software Process and Project Management, distributed-systems, secure-software-development, machine-learning.
- Milestones: canonical-papers reading in first semester; qualifying examination or research proposal review; industry or research practicum; teaching requirement (two courses); speaking and writing requirements; thesis proposal; dissertation; public defence.

## 10. Doubtful or incomplete

- Waterloo credit totals, Victoria's term-by-term list, Oxford's module names, CMU's current (post-2020) MSE plan and the CMU PhD's required courses were not retrievable; the CMU master's figures are from the legacy programme.
- Makerere's PhD page says three years but tabulates eight semesters.
- The only master's weekly syllabus found is a software-engineering-for-ML course (co-listed with undergraduates); the proposed Advanced Software Architecture, Analysis and Verification and Process courses are shaped from course titles and structures, not from retrieved syllabi.
- NUS MTech in Software Engineering, ETH's SE specialisation course list and several Oxford details came from search summaries only.
- The shared titles Graduate Research Methods, Computing Capstone Project, Concurrent and Parallel Programming and Logic and Formal Methods are used in the sibling Computer Science proposal; two programmes use the same definition.
