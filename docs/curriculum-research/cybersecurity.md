# Cybersecurity: curriculum research

Accessed 2026-10. Research for the CS Virtual Lab programme `cybersecurity`. University names appear only in this document.

## Summary

- Bachelor level: stand-alone "BSc Cyber Security" degrees are mostly three-year UK degrees (York, Liverpool) that are a Computer Science degree with a security pathway. The first year or two is the general CS core (programming, algorithms, architecture, theory, OS, networks), and security specialisation arrives in year 2 and 3 with an individual final-year project. US and South African practice is similar: security sits on top of a CS or IT core.
- Master's level: 1 to 2 years, 30 to 123 US credits/units or 180 UK credits. A small compulsory core (cryptography, network security, systems security, security management or risk, research methods) plus a specialisation or elective pool and a capstone, practicum or dissertation.
- PhD level: 72 credits in the US (about 48 coursework, 24 research) or a four-year UK Centre for Doctoral Training (taught first year, then research). Gates are a qualifying exam, an advisory committee, a proposal/comprehensive exam, at least one refereed publication and a public defence.
- The current platform list (18 cybersecurity courses) has a good applied spine (information security, ethical hacking, forensics, malware, SOC, cloud security) but is missing: security risk and governance, data privacy, applied cryptography beyond one combined course, systems/software security at graduate depth, advanced network security, security economics, privacy engineering, adversarial ML, hardware security, research methods at graduate level and any doctoral seminar. It also lacks the CS foundations that every reference programme requires (discrete mathematics, probability, data structures and algorithms, computer organisation, assembly, databases).

Limits of this research: several university pages were unreachable or returned binary PDFs in this session (ETH Zurich, UCL, Stanford CS 355, Royal Holloway PDF text, CS 6035 syllabus text, University of Pretoria yearbook). ## Common core across universities

1. Cryptography (applied, protocols): Georgia Tech, CUNY, Wits, Royal Holloway, Universiti Malaya, UCCS exam.
2. Network security: Georgia Tech, CUNY, Royal Holloway Core A, CMU networking core, Liverpool (computer networks + cyber), York.
3. Systems / operating system / software security (secure OS, secure systems engineering, secure computer systems, Computer Security): Georgia Tech, CUNY, Wits, Royal Holloway, Newcastle.
4. Security management, policy, risk: Royal Holloway (Security Management), Georgia Tech (policies and strategies), CMU (Cyber Risk Modeling), Wits (Data Privacy and Ethics).
5. Offensive security / ethical hacking / penetration testing: Wits, York, CUNY, Cincinnati.
6. Digital forensics and malware: Liverpool, York, Georgia Tech lab choice (malware analysis), Universiti Malaya, Cincinnati.
7. Research methods or capstone: Wits (Research Methods and Capstone), all master's end in a project, practicum or dissertation.
8. Bachelor foundations: programming, discrete mathematics/formal methods, algorithms, computer architecture, OS, networks, databases, software engineering.

## Prerequisite chains

- Programming (Python or C) -> data structures and algorithms -> operating systems -> secure software development / malware analysis (needs assembly).
- Discrete mathematics + probability -> cryptography -> applied cryptography -> provable security (doctoral).
- Networks I -> Networks II -> network security -> advanced network security -> security operations.
- Information security -> web application security / ethical hacking -> penetration testing -> security operations and incident response -> computer forensics.
- Computer organisation -> assembly -> malware analysis and reverse engineering (Wits and Georgia Tech expect OS, networks and architecture before graduate entry).
- Specific course prerequisites observed: University of Pretoria COS 330 requires COS 110 (introductory programming); Georgia Tech expects discrete mathematics, algorithms, OS, networks and architecture for admission.

## Representative weekly schedules

All schedules are copied from public calendars; where a site does not number weeks the calendar-week grouping is mine.

### Bachelor core: UC Berkeley, Computer Security (Fall 2026 offering, MWF lectures)

The public page gives lecture blocks in order, not week numbers (it also has "Buffer" lectures):

1. Security principles, x86 assembly and the call stack
2. Memory safety vulnerabilities and mitigations
3. Authentication, hashes, MACs, signatures, PKI
4. Symmetric encryption, authenticated encryption, Diffie-Hellman
5. How the Internet works, low-level network attacks, TLS, what TLS does not solve
6. End-to-end security and network defence
7. Web applications: SQL injection, XSS, web authentication, CSRF
8. UI security, isolation, AI security
9. Case studies: Signal and iPhone security

Assessment: Project 1 (memory safety, due Sep 18), Project 2 (cryptography, due Oct 30), Project 3 (web, due Nov 13), 7 homeworks, midterm Oct 8, final Dec 18. Grading weights and prerequisites are not stated on the page.

### Master's level: MIT 6.858 Computer Systems Security (Spring 2024)

A graduate/advanced-undergraduate course (level label not on the page). Calendar teaching weeks:

1. Introduction and threat models (Lab 1); OS and VM isolation
2. Software fault isolation (WebAssembly); trusted hardware
3. CPU side channels (Lab 2)
4. Privilege separation (OpenSSH); data centre infrastructure
5. Mobile phone security (iOS); web security model
6. Buffer overflow defences (Lab 3); symbolic execution
7. Verification (HACL*); Quiz 1 (lectures 1 to 12, labs 1 to 2); Lab 4 assigned
8. Supply chain security (guest); network security
9. Secure channels (TLS); certificates (Lab 5)
10. User authentication
11. Messaging security; key transparency
12. Anonymous communication (Tor); cybersecurity policy (guest)
13. Security economics; differential privacy
14. Information security in real life (guest)

Final exam May 22 (open laptop, lectures 13 to 24 and labs 3 to 5). Five labs.

Georgia Tech CS 6035 (Introduction to Information Security) lists topic areas but no weekly calendar: security basics, risk assessment, software and OS security, databases, cryptography, network authentication, malware, network threats, web and mobile security, legal/ethical/privacy issues; seven projects, five quizzes, one exam.

### Graduate reading seminar (closest public model to a doctoral seminar): Naval Postgraduate School, Advanced Topics in Computer Security (Summer 2014)

Weekly topics (three papers per week; session 1 previews, session 2 deep dive, session 3 follow-up papers and student presentations):

1. System security
2. Passwords
3. Encryption and PKI
4. Attacking encryption
5. Mixnets and Tor
6. Usability
7. Software security
8. Hardware security
9. Formal methods and semi-formal bug finding
10. Quantum computing and cryptography
11. Electronic voting

Assessment: participation 40% (two-paragraph assignments built on five reading questions), two take-home quizzes 30% each. This is a master's-level seminar and 12 years old; a current doctoral seminar with a full public week-by-week list was not found. Stanford's Topics in Cryptography (doctoral-level, rotating instructors, problem sets every two to three weeks) covers one-way functions to PRGs, commitments, attacks on RSA keys, zero knowledge, multi-party computation and lattice cryptography/LWE, but its schedule page could not be fetched in this session, so no weekly list is claimed.

## Proposed structure

### Bachelor of Science in Cybersecurity (4 years, 29 core + 10 elective pool, 4 electives required)

Core, in study order: principles-of-programming, introduction-to-python, discrete-mathematics, mathematics-for-computer-science, probability-and-statistics, fundamentals-of-computer-science, programming-with-c, data-structures-and-algorithms, computer-organization-and-architecture, assembly-language-and-microprocessors, operating-systems, computer-networking-i, database-systems-and-design, web-application-programming-i, systems-administration-i, computer-networking-ii, systems-administration-ii, information-security, NEW Security Risk Management and Governance, cryptography-and-network-security, web-application-security, secure-software-development, ethical-hacking-and-penetration-testing, security-operations-and-incident-response, computer-forensics, malware-analysis-and-reverse-engineering, cloud-security, legal-and-ethical-issues-in-computing, NEW Data Privacy and Protection.

Electives: theory-of-computation, cloud-computing, version-control-and-devops, containers-and-kubernetes, distributed-systems, blockchain-and-distributed-ledgers, internet-of-things, machine-learning, research-methods-in-computer-science, NEW Hardware and Embedded Security.

Capstone (not a catalogue course): individual final-year security project (York, Liverpool) and optional industry placement (Cincinnati co-op).

### Master of Science in Cybersecurity (1 to 2 years, 5 core + 8 elective pool, 4 electives required)

Core: NEW Graduate Research Methods, NEW Applied Cryptography, NEW Systems and Software Security, NEW Advanced Network Security, NEW Cyber Risk Modelling and Security Economics.

Electives: NEW Privacy Engineering and Privacy-Enhancing Technologies, NEW Security Analytics and Adversarial Machine Learning, malware-analysis-and-reverse-engineering, computer-forensics, distributed-systems, software-defined-networking, blockchain-and-distributed-ledgers, responsible-ai.

Milestones: industry-style practicum or capstone project (CMU 24 units, Georgia Tech 5 credits, CUNY 3 credits), research proposal, dissertation or research report with defence (Wits mini-dissertation, Royal Holloway 60 credits).

### Doctor of Philosophy in Cybersecurity (4 to 5 years, 3 core + 6 elective pool, 3 electives required)

Core: NEW Graduate Research Methods (shared), NEW Doctoral Research Seminar in Cybersecurity, NEW Provable Security and Cryptographic Protocols.

Electives: NEW Applied Cryptography (if not taken at master's), NEW Systems and Software Security, NEW Advanced Network Security, NEW Privacy Engineering and Privacy-Enhancing Technologies, NEW Security Analytics and Adversarial Machine Learning, NEW Cyber Risk Modelling and Security Economics. (The proposal JSON lists these as the pool.)

Milestones: written qualifying examination on core security topics (UCCS), oral qualifying examination with literature survey, advisory committee, dissertation proposal / comprehensive examination, teaching or lab assistantship, operational security placement of about 3 months (UCCS), at least one significant peer-reviewed publication, dissertation, public defence.
